# Catalogue redistribution review

Review date: 2026-11-13.

The private catalogue combines previously supplied title data with later community additions. One documented source is `jnetu/XboxAllTitle`, commit `7e5ec5230379dfc3539e046dcfbd7b6371521bbd`. Its repository root contains no license file, and GitHub reports `license: null`. Public access does not establish a redistribution license. Permission from that repository alone would not settle the provenance of all earlier entries or any underlying third-party rights.

All previously compiled catalogues and derived datasets are intentionally absent from this repository. The owner chose private publication without a supplied list; users must provide their own. The user's private application is unchanged. No request for permission has been sent.
